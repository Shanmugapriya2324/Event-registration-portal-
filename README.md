# Event Registration Portal

## Project Description
The Event Registration Portal is a web application that allows users to view events and register for them online. Administrators can manage events by adding, updating, and deleting event details.

## Features
- User Registration
- User Login
- Event Listing
- Event Registration
- View Registered Events
- Admin Event Management

## Technology Stack
- Frontend: React
- Backend: Spring Boot
- Database: MySQL
